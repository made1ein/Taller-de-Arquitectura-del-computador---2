Ejercicio 1 – Lectura de un número

¿Qué se debe hacer?

Crear un programa que solicite un número al usuario y después muestre el mismo número en pantalla.

Archivo: ej01.asm

Aquí debes colocar:

El código completo del ejercicio.

Los mensajes para solicitar y mostrar el número.

Comentarios que expliquen las instrucciones principales.
