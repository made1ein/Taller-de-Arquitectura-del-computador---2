# Taller-de-Arquitectura-del-computador---2

Indicaciones:

•	Trabajo en grupos de cuatro personas. Use el simulador RARS y la notación ABI para los registros (a0, t0, s1, etc.), no x5, x10.

•	Cada ejercicio se entrega en un archivo .asm con el número del ejercicio (ej01.asm, ej02.asm, …). Comente las líneas importantes.

•	Los programas que piden datos deben mostrar mensajes claros al usuario. Cada ejercicio vale 2 puntos.

•	Referencia de ecall en RARS: 1 imprime entero, 4 imprime cadena, 5 lee entero, 8 lee cadena, 11 imprime carácter, 10 termina el programa.
